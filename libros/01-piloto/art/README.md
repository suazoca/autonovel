## Rasgos fijos (cerrados en esta ronda)

- **Noha:** pelo oscuro corto; suéter coral/rojo; chaqueta oliva; pantalón
  gris; zapatos café.
- **Ivana:** dos coletas/moños con lazos mostaza; camisa mostaza; chaqueta
  lila; pantalón morado; tenis rojos; mochila café.
- **Dale:** gorra gris, chaqueta azul con parche, bastón de apoyo, cara cálida.
- **Jarrito:** barro naranja con flores azules suaves.

## Cómo ver las imágenes (fuera del chat)

El chat a veces no pinta los JPG. Usa una de estas formas:

1. **Galería HTML (recomendada)** — un solo archivo con las 7 imágenes
   embebidas:
   ```bash
   # en el navegador, abrir:
   # /root/ciudades-hn/libros/01-piloto/art/galeria.html
   xdg-open /root/ciudades-hn/libros/01-piloto/art/galeria.html
   # o, si hay servidor local en el worktree art:
   # http://127.0.0.1:8765/galeria.html
   ```
2. **Explorador del IDE** — carpeta `libros/01-piloto/art/` y clic en cada `.jpg`.
3. **Terminal** — `cd libros/01-piloto/art && ls` y abrir con el visor del sistema.

Copia portable: `/tmp/yamaranguila-galeria.html` (mismo contenido).
