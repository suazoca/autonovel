# ANTI-SLOP_INFANTIL

Cosas que el modelo (y el cansancio) meten solas en cuentos “para niños”.
Tachar en revisión.

## Tono y moral

- [ ] Cierre con lección explícita (“aprendieron que la amistad…”)
- [ ] Narrador que regaña o explica demasiado
- [ ] Dulzura vacía sin conflicto real (aunque sea chico)
- [ ] Ternura forzada (“sonrió con los ojitos llenos de…” en cada página)
- [ ] Giro bíblico / religioso (parábola, milagro de fe, oración como
      resolución mágica, “Dios quiso…”, allegoría de escritura sagrada)
- [ ] Usar la serie para catequesis o valores confesionales

## Estructura

- [ ] Relleno para inflar a 70 páginas sin beats nuevos
- [ ] Tres problemas distintos que no se tocan
- [ ] Final que resuelve un adulto mientras el niño mira
- [ ] Secuelas de novela (traición, corte, cliffhanger angustioso)

## Lenguaje

- [ ] Oraciones de párrafo académico
- [ ] Anglicismos de fantasía / YA
- [ ] Diminutivos en cada sustantivo
- [ ] Rimas forzadas si el libro no es en verso

## Lugar y cultura

- [ ] “Pueblito mágico” sin nombre real ni detalle local
- [ ] Comida / flora / clima genéricos de stock photo
- [ ] Etimología presentada como verdad única sin la regla de la biblia
- [ ] Estereotipos de pobreza, atraso o exotismo

## Emoción y seguridad (4–7)

- [ ] Susto que no se contine
- [ ] Burla o humillación del protagonista sin reparación
- [ ] Pérdida de un ser querido como motor (salvo tratamiento muy
      cuidadoso y fuera del piloto)
- [ ] Oscuridad de thriller “suavizada” con palabras tiernas

## Ilustración (briefs / prompts)

- [ ] Prompt que solo repite el texto
- [ ] Personajes que cambian de ropa/cara sin motivo
- [ ] Estilo distinto en cada página
- [ ] Texto dibujado dentro de la imagen (a menos que se pida a propósito)
- [ ] Miedo visual (sombras monstruo, sangre, caras grotescas)
